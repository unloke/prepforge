# 受測 agent 檢查指令

請審查 PrepForge Chess 固定版本 `aecebd3257ad375ed26b808da87b13bffc5aa582`，找出 Games、Scout、Analyze（含 Engine、Coach 與圖表）的功能錯誤、互動問題、版面／呈現問題，以及有實際依據的重複計算或資料來源問題。

只檢查，不修產品程式碼。從此版本的實作、`AGENTS.md` 及 `docs/README.md` 開始，不沿用歷史報告的結論。不要查看 benchmark 評分答案、本次用戶原始抱怨、其他 agent 的審查報告或解壓目錄之外的檔案。你可以閱讀源碼、使用瀏覽器、記錄請求／worker 工作，或用簡短腳本協助檢查。

使用用戶提供的測試帳號、輸入與啟動設定。若未另指定，桌面 viewport 為 1366×768 和 1440×900，zoom 100%。涵蓋正常使用、連續操作、首次載入和重複載入；自行選擇具體探索步驟。檢查期間內交付，不需要建立新的自動化測試系統。

請輸出 `findings.md`：

- 版本、環境、viewport、模型／engine、輸入資料及快取狀態；檢查時間、實際完成與未完成的範圍。
- 每個發現使用獨立 ID，寫清楚位置、前置條件、操作步驟、實際行為、預期行為、影響及證據路徑。說明是實際重現、源碼證據，還是待驗證假設。
- 動態問題附短錄影或有時間順序的日誌；版面問題附包含 viewport 的截圖；來源／配額問題附實際值及源碼路徑、行號或追蹤。程式碼推論不能冒充瀏覽器重現。
- 主觀視覺批評須指出具體元件與可觀察的差異，不能只說「醜」或「亂」。根因和改善建議分開寫；沒有證據時不要把猜測當根因。
- 未重現、模型不可用、資料不足等限制另列。未檢查不能寫成沒有問題。可記錄正面發現，但不要為湊數捏造錯誤。

交付原始報告及證據即可，不自行打分，也不要在交卷後改寫原始報告。評分會由用戶另外對表處理。
