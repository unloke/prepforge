## §0 診斷：v2~v11 為什麼「結構上」不可能實現理想

理想 = **特定**（具體到走法/線）× **個別**（是他，不是他那個分數段）
× **誠實**（統計上站得住）× **有效**（照著準備真的有用）。

v2~v11 十個版本，形態各異，但共享同一個致命前提：

> **弱點 = 一個「地方」（局面 / 線 / zone），證據 = 他在那個地方的
> 歷史戰績。**

這個前提下，「特定」和「誠實」互為死敵，因為證據單位是**經過那個
地方的棋局數**，而個別玩家在任何特定局面的樣本量幾乎恆為 1~5：

| 版本 | 犧牲了哪一角 | 死法 |
|---|---|---|
| v2 | 誠實 | n=1 手滑當弱點，巴納姆效應 |
| v3/v8 | 個別 | pool/Maia 稀釋，「去個人化」被用戶否決 |
| v9a | 特定+非空 | 誠實到只剩空白，self-test 輸出為零 |
| v11 | 特定 | zone 聚合買到統計力，代價是輸出攏統（地圖不是方案） |

這是一塊固定大小的餅：只要證據 = 「他在該處的結果」，
特定度 × 每處樣本量 ≤ 他的總棋局數。**在這個前提內不存在第 11 種
切法能同時保住四個角。** 所以 v12 不再切這塊餅——它換掉證據單位。

## §1 核心反轉：弱點不是「地方」，是「決策偏差」

一個棋手不是一張戰績地圖，是一個 **policy**：從局面到走法的函數。
他的弱點是這個函數的**系統性偏差**——「被將軍時總是退王不擋子」
「送兵他幾乎必吃」「劣勢時急著換后進殘局」「王前推兵毫不猶豫」。

換掉證據單位之後，樣本量問題**消失而不是被繞過**：

- 舊單位：經過局面 X 的棋局 → n ≈ 1~5。
- 新單位：**他做過的每一個決策** → 300 盤 × ~35 步 = **~10,000 個
  決策**。一個用特徵參數化的偏差假設（如「他比同分段玩家更愛吃
  送到嘴邊的兵」）可以從全部 10,000 個決策取證，n 以百計。

然後「特定」從哪裡來？——**不是從觀察來，是從推演來**（§6）：
把量到的偏差灌回 Maia，從開局向下 rollout，找出「他的偏差會把
概率質量灌進引擎驗證的壞地形」的具體線。輸出是一條線 + 一手棋 +
一條量測收據，不是 zone。

## §2 主張的三腿結構（每條腿獨立可證偽、各自 n 充足）

v2~v11 的單腿主張「他在這裡表現差（n=2）」換成三腿合取，
每條腿用**自己 n 最富餘的證據源**：

1. **偏差腿**（n ≈ 數千個決策）：「他有可量測的傾向 B」——
   相對 Maia baseline 的特徵偏差 + 同分段對照組 z 分數（§5）。
2. **懲罰腿**（引擎事實，n = ∞）：「T 型局面懲罰傾向 B」——
   Stockfish d18 驗證，根本不是統計命題。
3. **導向腿**（淺層轉移頻率，n 充足）：「你能把棋帶進 T」——
   entry fork 只用他 trie 的**淺層**節點（ply ≤ 8~10），那裡的
   per-node 樣本天生最大（漏斗頂端），Wilson LB 現貨可用。

注意樣本量結構整個反轉了：舊設計需要他在**樹深處**有樣本
（恆為 ≈1），v12 只需要他在（a）特徵層（上萬）和（b）樹淺層
（上百）有樣本。樹深處他 n=0 的地方，由被他自己的偏差校準過的
模型接手——而且印出來的主張誠實地反映這一點（§8）。

## §3 特徵庫（本設計的成敗處）

~30–40 個可解釋、chess.js 可廉價計算的 (position, move) 特徵。
垃圾特徵 = 巴納姆；特徵庫要當產品資產維護。首版候選：

**物質/交換類**：is-capture、吃向中心/邊、gambit 兵接受（吃掉
對方主動送的兵）、exchange sac 接受/拒絕、優勢時簡化 vs 劣勢時
簡化（換后 conditional on eval sign——需 enrich 後的粗 eval 或
用物質差代理）。

**王安全類**：王前兵推進（g/h/f 在己方王翼）、易位時機（延遲
易位 ply 數）、被將軍時的應對類型（擋/吃/走王）、對攻中先手
vs 防守選擇。

**空間/結構類**：過 4 排推進、piece retreat、fianchetto、
中心兵張力保持 vs 立即解決、rook lift。

**時間/節奏類**（ND-JSON 時鐘現貨）：per-move think time vs
局面複雜度（用 Maia entropy 當複雜度代理）、長考後犯錯率、
時間領先/落後時的決策質變。

**相位類**：queenless middlegame、同色格 bishop 殘局等粗相位
標籤下的分佈級表現（v9 §D 的教訓：不做點尖峰檢測，只做
分佈級對比）。

每個特徵是 (position, move) → ℝ 的純函數，對「他走的那手」和
「Maia top-k 備選」都算，偏差 = E_him[f] − E_maia[f]。

## §4 個人殘差模型：log-linear tilt on Maia

把 ~40 個偏差係數擬合成一個透明的殘差模型：

```
p_him(move) ∝ p_maia(move) × exp(Σ_f β_f · f(position, move))
```

β 用他全部 ~10k 決策做 logistic/multinomial 迴歸擬合。
就 40 個係數，每一個單獨可解釋、可印出（「β_gambit-accept =
+1.3，即送兵他吃的 odds 是同分段的 3.7 倍」）。

**與已廢棄 slip-model 的區別（必須說清楚，那是 7/01 的血）**：
slip-model 死於（a）在 gate 篩過的樣本上訓練 → selection bias、
（b）per-game 分類任務本身 ill-posed（75% 手滑無痕跡）。v12 的
迴歸**沒有 gate、沒有篩選**——他每一手都是訓練資料，任務是
「預測他下哪手」而不是「分類這盤是不是手滑」。手滑在上萬個
決策裡自然被平均掉，這正是換證據單位的紅利。

**與 v3「Maia 污染去個人化」的區別**：v3 用 Maia **冒充**他
（Maia 是主詞）；v12 用 Maia 當**背景板**，訊號恰恰是他偏離
Maia 的部分（他是主詞，Maia 是量尺）。方向相反。

## §5 對照組：cohort z 分數（v11 洗牌檢定的正確位置）

Maia 不是完美的分段基準，raw 偏差可能是 Maia 的 artifact。
解法：對 **同分段對照 cohort**（scout-fetch-games.mjs 抓
~20 個同 band、同 speed 玩家 × 100 盤，離線一次性）跑**完全
相同的管線**，得到 cohort 的 β 分佈。他的每個 β 換算成
cohort z 分數——Maia 的系統誤差是 common mode，相減即消。

- 只有 |z| ≥ 閾值（由 cohort 成員互相之間的 z 分佈定，不拍腦袋）
  的特徵准掛「他的傾向」。
- ~40 個特徵做多重比較校正（FDR）。n 夠大，校正後仍有牙齒。
- 朋友對 v11 §4 的分層要求（speed/時間窗/對手強度）在這裡
  自然滿足：cohort 按 speed 和 band 抓，時間窗用他自己的
  time-split 信度檢定（§7.1）覆蓋。

## §6 推薦鏈：固定順序，rollout 只當排序官不當作者

**禁止的鏈（幻覺鏈）**：`他愛吃兵 → 生成一條騙吃兵的線 →
Maia rollout 說有利 → 輸出`。rollout 說有利不構成任何主張。

**唯一合法的鏈（順序不可調換，每一環獨立否決）**：

1. **個人偏差證據**（§4/§5 過關的 bias，含 cohort z 與 n）。
2. **候選觸發局面**：能把該偏差擺上檯面的局面族——來源是
   引擎/理論上已知健全的線（explorer 現貨 + d18），不是
   為偏差現編的線。
3. **Stockfish 安全性**：整條線對你不虧（entry ≥ −40cp 否決官，
   關鍵分支 d18 驗證）。不健全的「陷阱」直接死，無論偏差多強。
4. **可到達性**：他 trie 淺層轉移頻率（Wilson LB）證明他可能
   走進來。
5. **多樣性**：同一偏差須導出 ≥3 條入口不同的路線（§8 Route
   Set），導不出就整個偏差不進 prep 輸出（§7 第 5 關）。

tilted rollout 的唯一職權：對**已通過 2–4 的候選**做排序
（EV(tilted) − EV(raw)，只有「因為是他」才多賺的部分算分）。
prep gain 是內部排序量，**永不印出**（繼承 v8 的 prepGain
never-printed 條款）。他實際面對過該線且戰績差（v9a B 類）
作為加分收據附上，不是 gate。

## §7 Falsification harness（先做，UI 一行不寫）

全部 Node 離線（maia-policy-dump + backtest 兩個 harness 現貨
可改造），四道關卡按序，任一道跪了就地停工，成本止於腳本：

1. **信度（test-retest）**：他的棋局按時間對半切，兩半各擬合
   β，向量相關 ≥ 閾值。不穩定的「偏差」不是 trait，是噪音。
   目標產出：**5–10 個穩定偏差**（多於此按 |z| 截斷，少於此
   誠實報告）。
2. **鑑別度**：他的 z 向量要比 cohort 成員互相之間更突出；
   同時跑兩種 decoy（現貨 scout-decoy 思路）：合成「純 Maia
   玩家」與「均勻隨機合法著法玩家」，管線對前者必須輸出
   全零偏差、對後者不得產出成串偽傾向。
3. **預測力（本設計的生死關）**：held-out 棋局上，tilted
   policy 預測他實際走法的 log-loss / top-1 必須顯著優於
   raw Maia。**贏不了 raw Maia = 「個人化」是假的 = 整個
   設計死刑**——這個判決在寫任何 UI 之前就會下來。這一關
   同時是對「Maia 幽靈主角」疑慮的實證回答：如果偏差只是
   Maia 的 artifact，它在 holdout 上不會有預測力。
4. **臉譜效度**：跑用戶本人帳號，印出他的 top 偏差（人話版），
   本人裁決「這像不像我」。v11 驗收條款直接繼承。
5. **路線可導出性（prep 資格關）**：每個過關偏差必須能按 §6
   合法鏈導出 ≥3 條 Stockfish 不虧、**開局入口互不相同**的
   路線。**1–4 過而 5 不過 → v12 降級為「玩家分析報告」
   （Bias Card only），不得做 Scout prep 輸出**；1–4 任一
   不過 → 整案停工。

## §8 輸出形態（三層）與主詞紀律

輸出 = **Bias Card → Route Set → Receipts** 三層，v2 的
「一頁一個決定性主張」精神保留在 Bias Card 層。

1. **Bias Card 偏差卡**（每色 ≤5 張）：一個過五關的個人傾向，
   人話一句 + 量測收據。範例：「他比同分段玩家更常接受翼側
   兵，尤其后還在棋盤上時（他 68% vs 同分段 34%，取證於他的
   214 個同類決策，z=3.4）。」
2. **Route Set 路線組**：同一張卡下 3–5 條**風格互異**的路線，
   各掛風險等級標籤：穩健（小優/安全/易記）、鋒利（強迫他
   做偏差決策，風險標明）、轉置（從他常見開局進入同類結構）、
   低理論（避開大眾主線但引擎不差）。全部通過 §6 合法鏈。
3. **Receipts 收據**（每條路線必列）：他歷史中同類決策出現
   次數、偏差相對 cohort 的 z、引擎驗證不虧、前幾手走進來的
   到達率（Wilson LB）、路線風險等級。

**主詞紀律（硬條文，進禁詞渲染測試）**：

- 禁：「他會這樣下」「他會走 X」及一切對他未來著法的斷言句式。
- 准：「他的歷史決策比同分段基準更常偏向這類選擇」。
- 樹深處的預測只准印「他的量測傾向使這手回應顯著更可能」。
- 主詞分級（他 / players at his level）規則繼承 v8；禁詞渲染
  測試（v6 §deliverable）保留並加入上述句式。
- Maia 不可用 → 整個 v12 不可用（Maia 是量尺不是配菜），
  誠實降級到 v7，不縮水冒充。

## §9 與 v11 的關係、風險清單

- v11 的 zone 地圖降為**導航/上下文層**（可選）：偏差頁可以標
  「此傾向在你的 Najdorf zone 內最常被觸發」。Pressure 標籤、
  instabilityRate 主幹廢除；洗牌對照的靈魂遷移到 §5 cohort z。
- 風險：①特徵庫垃圾進垃圾出——靠 §7.2 decoy + FDR 擋；
  ②cohort 抓取的工程成本（一次性離線，可接受）；③迴歸把
  時代混雜當 trait（他一年前的棋風）——time-split 信度 +
  可選 recency 加權；④「傾向可利用但導不進去」（懲罰腿過、
  導向腿跪）→ 該頁誠實不出，寧缺毋濫，但因為傾向是全局性的
  （不綁單一局面），可導向的 T 型局面通常不只一族——這是
  相對 v9a 空白問題的結構性改善，不是承諾。

## §10 施工順序

1. 特徵庫 v1（~30 個特徵的純函數 + 單元測試，零依賴先行）。
2. 改造 maia-policy-dump：對他每個決策點 dump top-k policy +
   特徵值 → 決策矩陣 JSON。
3. β 迴歸 + §7.1/7.2（信度、鑑別度、decoy）。
4. cohort 抓取 + z 分數。
5. **§7.3 預測力生死關**（unbrainless87 + 用戶本人帳號）。
6. 過關後才有資格談：tilted rollout、輸出頁、UI（?scoutV12=1，
   v7 仍為預設）。
